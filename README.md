# StellarCalc: Interstellar Distance & Relativistic Voyage Calculator

StellarCalc is an interactive science educational tool and mission planning simulator that calculates relativistic time dilation, Lorentz factors, and propulsion fuel requirements for interstellar voyages to real exoplanets and star systems.

## Features

- **Real Exoplanet Destinations**: Select from Proxima Centauri b, Barnard's Star, Sirius, Tau Ceti e, Kepler-186f, or input custom light-year distances.
- **Relativistic Time Dilation (Lorentz Factor)**: Computes proper time experienced by the onboard crew versus elapsed time in the Earth reference frame as velocity approaches the speed of light ($c$).
- **Propulsion & Tsiolkovsky Calculations**: Compares chemical/ion drives against advanced fusion, antimatter, and beamed laser sails, computing required reaction mass ratios.
- **Interactive Spacetime Visualization**: Dynamic HTML5 Canvas rendering comparing Earth elapsed time against crew aging curves.
- **Accessible & Responsive**: Fully responsive design with keyboard-friendly inputs and clear scientific explanations.

## Local Run Instructions

1. Download or clone all project files (`index.html`, `style.css`, `script.js`, `README.md`) into a single folder.
2. Open `index.html` directly in any modern web browser (Chrome, Firefox, Safari, Edge).
3. No build tools, package managers, or network requests are required. This is a fully self-contained static project.
